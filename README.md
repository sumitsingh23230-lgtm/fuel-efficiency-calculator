Fuel Efficiency Calculator

Project Overview

This is a beginner-level Python project that calculates vehicle fuel efficiency.

Objective

To calculate fuel efficiency using distance travelled and fuel consumed.

Formula

Fuel Efficiency = Distance Travelled / Fuel Consumed

Example

Distance: 150 km
Fuel consumed: 5 litres
Fuel efficiency: 30 km/L

Python Concepts Used

- Variables and data types
- Functions
- Arithmetic operations
- Conditional statements
- Exception handling
- User input and output

How to Run

1. Open "fuel_efficiency.py".
2. Run it using Python 3.
3. Enter the distance and fuel consumed.
4. View the calculated fuel efficiency.

Limitation

This project calculates fuel efficiency from user input. It does not use machine learning.
